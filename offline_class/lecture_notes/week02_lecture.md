# Week 02 - K-최근접 이웃을 이용한 생선 분류

## 배운 내용

- 도미 35마리와 빙어 14마리의 길이·무게 데이터 정리
- `zip()`과 리스트 내포를 이용한 2차원 학습 데이터 생성
- 지도학습과 이진 분류, 타깃 데이터의 의미
- `KNeighborsClassifier` 모델 생성 및 학습
- `fit()`, `score()`, `predict()`, `predict_proba()` 활용

## 1. 학습 데이터 준비

도미 35마리와 빙어 14마리, 총 **49마리**의 생선 데이터를 사용한다. 각 생선은 길이와 무게라는 두 특성을 가진다.

```python
# fish_length, fish_weight는 앞선 실습에서 정의한 길이·무게 리스트
print(len(fish_length))  # 49
print(len(fish_weight))  # 49
```

각 생선의 길이와 무게를 한 쌍으로 묶어야 한다. `zip()`은 두 리스트에서 같은 위치의 값을 짝지어 주고, 리스트 내포는 그 결과를 2차원 리스트로 만든다.

```python
fish_data = [[l, w] for l, w in zip(fish_length, fish_weight)]
print(fish_data[:5])  # 처음 5개 샘플 확인
```

- `fish_data`의 샘플 하나는 `[길이, 무게]` 형태이다.
- 전체 학습 데이터는 **49행 × 2열** 형태이다.
- `[:5]`는 리스트의 첫 다섯 요소를 확인하는 슬라이싱이다.

## 2. 정답(타깃) 데이터 생성

**지도학습**은 입력 데이터와 함께 정답을 제공해 학습하는 방법이다. 강의에서는 도미를 `1`, 빙어를 `0`으로 지정한다.

```python
fish_target = [1] * 35 + [0] * 14
print(fish_target)
```

- `fish_data`: 생선의 길이와 무게(입력 데이터)
- `fish_target`: 도미인지 빙어인지 알려주는 정답(타깃 데이터)
- 두 종류 중 하나로 분류하는 문제이므로 **이진 분류**에 해당한다.

## 3. K-최근접 이웃(K-Nearest Neighbors, KNN)

KNN은 새로운 데이터와 기존 데이터 사이의 거리를 비교하여 **가장 가까운 K개 이웃**의 분류를 참고한다. 예를 들어 가까운 이웃 5개 중 도미가 3개, 빙어가 2개라면 도미로 분류한다.

2개 특성(길이와 무게)을 사용할 때 거리 계산의 한 예는 유클리드 거리이다.

\[
d = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}
\]

## 4. 모델 생성, 학습 및 평가

`scikit-learn` 라이브러리의 `KNeighborsClassifier`를 사용한다.

```python
from sklearn.neighbors import KNeighborsClassifier

kn = KNeighborsClassifier()  # 모델 객체 생성
kn.fit(fish_data, fish_target)  # 학습
print(kn.score(fish_data, fish_target))  # 학습 데이터에서 정확도 확인
```

강의에서 확인한 정확도는 `1.0`(100%)이다. 다만 **학습에 사용한 데이터로 다시 평가한 결과**이므로, 새로운 데이터에서도 정확도가 100%라고 판단할 수는 없다. 학습용 데이터와 테스트용 데이터를 나누는 방법은 다음 수업에서 다룰 예정이다.

## 5. 새로운 생선 예측

`predict()`는 새 생선의 분류 결과를 반환한다. scikit-learn에 입력하는 샘플은 **2차원 형태**로 작성한다.

```python
print(kn.predict([[30, 600]]))  # 강의 예제: 도미(1)로 예측
print(kn.predict([[10, 65]]))   # 강의 예제: 빙어(0)로 예측
```

여러 샘플에 대한 예측도 한 번에 수행할 수 있다.

```python
pred = kn.predict(fish_data)
print(pred)
```

## 6. 분류 확률 확인

`predict_proba()`는 각 클래스에 대한 분류 확률 추정값을 반환한다.

```python
one = [[10, 150]]
print(kn.predict(one))        # 예측 클래스
print(kn.predict_proba(one))  # 클래스별 확률 추정값
print(kn.classes_)           # 확률 열의 클래스 순서 확인
```

강의에서는 `[10, 150]` 샘플의 예측 결과가 `0`이고, 클래스 `0`과 `1`에 대한 확률이 각각 `0.8`, `0.2`인 예를 설명했다. 실제 출력은 사용한 데이터와 모델 설정에 따라 달라질 수 있다.

## 핵심 함수 정리

| 함수 / 문법 | 역할 |
| --- | --- |
| `len()` | 리스트 원소 개수 확인 |
| `zip()` | 여러 리스트의 같은 위치 값을 묶기 |
| `[[l, w] for l, w in ...]` | 2차원 리스트 생성 |
| `fit(X, y)` | 입력 데이터와 타깃으로 모델 학습 |
| `score(X, y)` | 분류 정확도 확인 |
| `predict(X)` | 클래스 예측 |
| `predict_proba(X)` | 클래스별 확률 추정값 확인 |
