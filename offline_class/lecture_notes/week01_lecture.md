## 1. 수업 개요

과목명은 **고급 파이썬 프로그래밍**이지만, 이번 학기의 실제 중심 내용은 **인공지능(AI)**이다.

고급 파이썬에서는 통계 분석, 모델링, 시각화 등 여러 내용을 다룰 수 있지만, 이번 수업에서는 인공지능의 전체 내용을 깊게 다루기보다는 실제 구현에 필요한 핵심 내용을 중심으로 학습한다.

### 이번 학기의 핵심 학습 내용

1. **분류(Classification)**
   - 입력 데이터를 여러 클래스 중 하나로 구분
   - 예: 고양이 / 개, 버스 / 승합차

2. **회귀(Regression) / 값 예측**
   - 하나의 연속적인 값을 예측
   - 예: 내일의 기온, 미세먼지 수치 등

3. **신경망(Neural Network)과 딥러닝 기초**
   - 사람의 뉴런 구조를 본떠 만든 신경망의 기본 개념
   - 깊은 신경망을 사용하는 딥러닝의 기초까지 학습 예정

## 2. 인공지능 · 머신러닝 · 딥러닝

### 인공지능(Artificial Intelligence)

사람처럼 **학습하고 추론할 수 있도록 만든 모든 기술과 방법**을 포괄하는 가장 큰 개념이다.

### 머신러닝(Machine Learning)

데이터를 주면 컴퓨터가 그 데이터에서 **규칙을 스스로 학습하도록 하는 방법**이다.

기존의 프로그램은 프로그래머가 규칙을 직접 작성했다.

```text
길이가 30 이상이면 도미
길이가 30 미만이면 빙어
```

반면 머신러닝은 여러 도미와 빙어 데이터를 먼저 주고, 컴퓨터가 데이터를 통해 두 생선을 구분하는 규칙을 스스로 찾도록 한다.

### 딥러닝(Deep Learning)

머신러닝 방법 중에서도 **신경망을 기반으로 하는 방법**이다.

```text
인공지능(AI)
└── 머신러닝(Machine Learning)
    └── 딥러닝(Deep Learning)
```

## 8. 첫 번째 머신러닝 문제

이번 주부터 본격적인 머신러닝 실습을 시작한다.

첫 번째로 사용하는 알고리즘은 **K-최근접 이웃(K-Nearest Neighbors, KNN)**이다.

### 목표

생선의 다음 두 가지 특징을 이용한다.

- 길이(length)
- 무게(weight)

이를 통해 생선이 다음 중 어느 종류인지 분류한다.

- **도미(Bream)**
- **빙어(Smelt)**

```text
생선의 길이 + 무게
        ↓
K-최근접 이웃 알고리즘
        ↓
도미 / 빙어 분류
```

## 9. 데이터와 특성(Feature)

머신러닝에서는 어떤 데이터를 사용하는지가 매우 중요하다.

강의에서는 임의로 만든 데이터보다 **출처와 신뢰성이 있는 데이터**를 사용하는 것이 중요하다고 강조하였다.

이번 실습에서는 공개된 생선 데이터에서 필요한 부분을 사용한다.

### 사용할 데이터

#### 도미

- 총 **35개**
- 길이 데이터
- 무게 데이터

#### 빙어

- 총 **14개**
- 길이 데이터
- 무게 데이터

### 사용할 특성

원래 데이터에는 여러 항목이 있지만 이번 실습에서는 다음 두 가지만 사용한다.

```text
길이(length)
무게(weight)
```

이처럼 머신러닝이 판단에 사용하는 데이터의 항목을 **특성(Feature)**이라고 한다.

## 10. 리스트 데이터

도미와 빙어의 길이와 무게는 각각 Python 리스트로 저장한다.

형태는 다음과 같다.

```python
bream_length = [...]
bream_weight = [...]

smelt_length = [...]
smelt_weight = [...]
```

각 생선의 길이와 무게는 서로 한 쌍을 이루므로 두 리스트의 원소 개수가 같아야 한다.

예를 들어 도미의 경우:

```text
bream_length : 35개
bream_weight : 35개
```

둘 중 하나의 데이터가 빠지면 하나의 생선에 길이 또는 무게가 없는 잘못된 데이터가 된다.

## 11. 데이터 시각화

숫자만 나열해서 보는 것보다 그래프로 표현하면 도미와 빙어 데이터의 차이를 훨씬 쉽게 확인할 수 있다.

이번 실습에서는 **산점도(Scatter Plot)**를 사용한다.

### matplotlib

Python에서 그래프를 그리기 위해 **matplotlib** 라이브러리를 사용한다.

```python
import matplotlib.pyplot as plt
```

### 코드 해석

```python
import matplotlib.pyplot as plt
```

- `matplotlib` : 그래프 관련 라이브러리
- `pyplot` : 그래프를 그리는 기능을 제공하는 모듈
- `as plt` : `matplotlib.pyplot`을 앞으로 `plt`라는 짧은 이름으로 사용

---

## 12. 도미 데이터 산점도

```python
plt.scatter(bream_length, bream_weight)
plt.xlabel('length')
plt.ylabel('weight')
plt.show()
```

### 의미

```python
plt.scatter(x축 데이터, y축 데이터)
```

이번 실습에서는:

```text
X축 → 생선의 길이
Y축 → 생선의 무게
```

를 사용한다.

## 13. 도미와 빙어를 한 그래프에 표시

두 종류의 데이터를 같은 그래프에 표시한다.

```python
import matplotlib.pyplot as plt

plt.scatter(bream_length, bream_weight)
plt.scatter(smelt_length, smelt_weight)

plt.xlabel('length')
plt.ylabel('weight')

plt.show()
```

한 그래프에 두 종류의 점이 나타나므로 **도미와 빙어의 길이·무게 분포 차이**를 눈으로 확인할 수 있다.

이 단계에서는 아직 KNN 모델을 실제로 학습시키기 전이며, 먼저 **데이터를 확인하고 시각화하는 과정**까지 진행하였다.

## 14. 기존 프로그래밍과 머신러닝의 차이

### 기존 프로그램

사람이 직접 규칙을 작성한다.

```text
입력 데이터
    ↓
사람이 만든 규칙
    ↓
결과
```

예:

```python
if length >= 30:
    # 도미라고 판단
    ...
```

### 머신러닝

컴퓨터에게 정답이 포함된 데이터를 먼저 주고 학습시킨다.

```text
학습 데이터
    ↓
머신러닝 알고리즘
    ↓
데이터의 규칙 학습
    ↓
새로운 데이터 분류
```

즉, 머신러닝의 핵심은 **데이터로부터 규칙을 학습하는 것**이다.

## 15. K-최근접 이웃(KNN) 핵심 개념

이번 주에는 KNN을 이용해 도미와 빙어를 분류하는 작업을 시작한다.

KNN은 새로운 데이터가 들어왔을 때 주변에 있는 기존 데이터들을 참고하여 어느 클래스에 가까운지를 판단하는 분류 알고리즘이다.

> 1주차 오프라인 녹음에서는 KNN 모델을 완전히 구현하기보다는  
> **문제 정의 → 데이터 준비 → 데이터 시각화** 단계까지 주로 진행되었다.
